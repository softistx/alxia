New subpath `@alxia/react-router/link`: `RouterLink` and `RouterLinkProps`, React Router's `Link` as the link component of a UI library that hands an `href` and spreads anchor props (a `LinkComponentProvider`). It takes `href` (or `to`) and passes `className`, `children`, `ref` and every other prop on; imports `react` and `react-router` alone. Additive.
