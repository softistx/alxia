Dev comfort. `alxia({ dev })`, on only when `NODE_ENV` is `development` (it fails closed: unset, `staging` or `Production` leave it off), turns on what helps the developer running the app, and costs nothing outside dev: `listen` prints its URL and the route table — each route's method, path, middlewares and handler, sockets, directories, files and pages marked — or tells `listen({ onListen })` instead, in every mode, with a `ListenInfo` (`url`, `routes` as `RouteRow`s, `table`, `dev`); the router's 404 carries a `hint` naming the closest declared route (`did you mean GET /todos/:id?`), never one behind a group's, a prefixed plugin's, a `use(path, …)` or its own middleware, and its 405 the methods allowed; a 500 answers a browser with an HTML page of the error — its name, message, stack with the app's own frames marked, the source around the throw, the method, path and route — under its own nonce Content-Security-Policy, and any other client with a `stack` member (an extension under `errors: 'problem'`). In every mode, a factory given uncalled — `use(cors)`, a route's `logger`, `plugin(health)` — throws where it is declared, `use(): argument 1 looks like a factory (cors): call it, use(cors())`, where it answered every request 500; `markFactory(fn, kind?)` marks one of your own, and TypeScript refuses any, marked or not. `compose(...middlewares)` is one middleware typed for any number of them, spliced into the chain where it stands, and a ninth middleware in a call is one error naming the limit, `at most 8 middlewares per route: group them with compose(...)`. `use(validate({}))` is a compile error again. `isDev(ctx)` says whether the app serving the request is in dev, for a plugin that helps there alone. The warning of a middleware given after routes follows the app's dev switch, `alxia({ dev })` included, rather than `NODE_ENV` alone. `compose(a, b)` whose `b` reads a key `a` adds with another type is one error on the call, `` `user` is in the context with another type than this middleware reads ``, as on a route.
