A new package, `@alxia/create`: `bun create @alxia [dir] [--template api|react-router]` writes a new alxia app — an API with Zod, a route hook, a spec and the typed client, or React Router's official template with `@alxia/react-router` added — with its dependencies at the newest versions alxia's peers accept.
