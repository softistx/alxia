# @alxia/i18n documentation

The [package README](../README.md) is the short version. This folder is
the long one: the catalogues and every option, what the routes behind the
plugin read, how messages are formatted and keys typed, where the
request's language reaches and where it does not, and what to do when a
response shows a key or the wrong language.

| Page | Read it when |
| --- | --- |
| [Guide](guide.md) | writing the catalogues, choosing where the language is read from, reading a user's saved language from an earlier plugin, typing a function that translates, translating in a service or an error handler, caching the responses, or testing them |
| [Troubleshooting](troubleshooting.md) | `createI18n()` threw at start-up, `tsc` refused a key, an option or `plugin(i18n)`, a function generic over its catalogues hit TS2589, the log shows an ICU error, or a response shows a key or the wrong language |
| [Roadmap](roadmap.md) | wondering what is coming, and what is not planned |
