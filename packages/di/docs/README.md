# @alxia/di documentation

The [package README](../README.md) is the short version. This folder is the
long one. The Container, Tokens, lifetimes and Slots themselves are
[`@nxgt/di`'s documentation](https://github.com/softistx/nxgt-di/tree/develop/packages/di/docs).

| Page | Read it when |
| --- | --- |
| [Request Scopes](guide/request-scopes.md) | giving routes a Scope, computing Slots from the context, exposing values to a group or a route, streaming, or testing a route |
| [Lifecycle](guide/lifecycle.md) | booting the Container with `init`, disposing of it on stop, or sharing it between forks |
| [Troubleshooting](troubleshooting.md) | `tsc` refused a `di`, a `use` or an `expose`, or a request failed with an error from this package |
| [Roadmap](roadmap.md) | wondering what is coming, and what is not planned |
