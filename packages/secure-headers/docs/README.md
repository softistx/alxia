# @alxia/secure-headers documentation

The [package README](../README.md) is the short version. This folder is
the long one: every option with its default, which responses get the
headers, and what to do when a browser refuses what they forbid.

| Page | Read it when |
| --- | --- |
| [Guide](guide.md) | changing or dropping a header, a nonce per request, giving a page its own policy, ordering it with other middlewares, or testing the headers |
| [Troubleshooting](troubleshooting.md) | something went wrong and you have the message: a TypeScript error, a browser refusal, a header that is or is not there |
| [Roadmap](roadmap.md) | wondering what is coming, and what is not planned |
