# Roadmap

What `@alxia/access` gives an app, and what is coming. This page is a
direction, not a commitment.

## Now

- **The first release.** The `<area>:read|manage` permission, the role
  catalogue built from the module registry with its boot errors, the request
  guards, and the refusal mapping hook.

## Next

- **Viewer permissions for a shell.** The permissions a viewer holds in a
  tenant, exposed so a UI shell can filter its menus.

## Later

Nothing scheduled yet.

## Not planned

- **Several roles per member, or per-user grants.** A member has one role
  per tenant; the matrix is the modules' defaults.
- **A GraphQL server or a database.** The host brings them.

## Shipped

Nothing yet.
