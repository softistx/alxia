# @alxia/language documentation

The [package README](../README.md) is the short version. This folder is
the long one: every option with its default and an example, how a
request's language is found and how `Accept-Language` is negotiated, what
the routes behind the plugin read, and what to do when a response is not in
the language you expected.

| Page | Read it when |
| --- | --- |
| [Guide](guide.md) | choosing the sources and their order, reading the language from the path, keeping a choice in a cookie, typing what the routes read, caching the responses, or testing them |
| [Troubleshooting](troubleshooting.md) | the plugin threw at start-up, `tsc` refused an option or a route, or a response is in the wrong language |
| [Roadmap](roadmap.md) | wondering what is coming, and what is not planned |
