# @alxia/cors documentation

The [package README](../README.md) is the short version. This folder is
the long one: every option with its default and an example, what a refused
origin gets, where the plugin sits among an app's hooks, and what to do
when a browser still refuses a call.

| Page | Read it when |
| --- | --- |
| [Guide](guide.md) | choosing the origins, sending cookies cross-origin, exposing a header, ordering `cors()` among other hooks, or testing a preflight |
| [Troubleshooting](troubleshooting.md) | a browser blocked a call and you have the console message, or `tsc` refused an option |
| [Roadmap](roadmap.md) | wondering what is coming, and what is not planned |
